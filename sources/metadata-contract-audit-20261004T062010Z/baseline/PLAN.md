# P1-A: existing checks and simple baseline audit

This is an AI-agent audit, not independent human validation. All prior evidence is read-only. No emulator or Android execution is allowed. New outputs are confined to this `baseline` directory; Python bytecode writes are disabled.

## Fixed scope

Use exact preserved E1/E2 artifacts and deduplicate by complete file SHA-256 before any run: original, description control, label deletion, cyclic permutation, and restored labels. The two phases contain eight aliases but five distinct files. Restoration aliases are retained together, and no file is replaced if a check fails.

For each distinct file, run the following and retain command arguments, timestamps, stdout/stderr, status, diagnostics and stage:

1. Official Support 0.4.4 MetadataDisplayer: read embedded JSON and associated payloads. Successful display is not called validation.
2. Official MetadataPopulator: load the original embedded metadata and populate a new writable model copy. Metadata-entry count and label-string count are recorded separately.
3. A simple static baseline for the already selected single-output category path: inspect the graph shape/signature and the unique TENSOR_AXIS_LABELS resource; apply the exact list-overload TensorLabel first-nonunit-axis, label-cardinality, last-axis and flattened-cardinality conditions. Unknown bindings/dynamic shapes abstain. This is a scoped reimplementation of existing conditions, not a semantic oracle or a new general analyzer.
4. The unchanged existing E5 preflight implementation, preserving its complete report. A launcher replaces only its common.run logging helper because the original helper appends to sealed commands-executed.sh. The original preflight and codegen source bytes remain unchanged. The logger executes identical subprocess arguments, with new output locations and a new working directory, and logs only here. The adaptation will be disclosed in results.
5. Official Python/C++ Task ImageClassifier initialization with CPU, one thread and max_results=-1. No classify, inference or Android call is made by this audit.

Additionally retain the already preserved EfficientNet output-metadata-entry count-minus-one fixture as a separate structural negative control. Run Displayer and Populator only; do not pool it with the five label-resource conditions or assume it has a selected label decoder binding. Disassemble the exact Support API jar used by the Android build to check the source-derived baseline conditions against its TensorLabel bytecode.

Read-only source review covers E5 template extraction, unknown-pattern behavior, dynamic abstention, actual Task CreateFromOptions/CheckAndSetOutputs, and the exact TensorLabel axis condition. No claim of generic source-to-binary equivalence is planned.

## Decision boundaries

Do not assume E5 detects more than the simple baseline or Task initialization. Compare the five outcome vectors, earliest observed stages and supplied diagnostics. A label permutation that passes count/shape rules is not a demonstrated semantic false negative, since no independent class-order reference is supplied. Preserve negative and blocked outcomes. Do not treat newly executed checks as independent model observations or a human audit.

## Preservation and deliverables

Record original scripts, model digests, library identities and the old commands-executed.sh hash before execution and afterward. Store source snapshots/line anchors, PLAN.md, RESULTS.md, results.json, commands, stdout/stderr, version data and SHA256SUMS. Files regenerated by MetadataPopulator are audit outputs, never replacements for originals.
