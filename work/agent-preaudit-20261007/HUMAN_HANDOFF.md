**需要你明确决定的两项：**

1. **“预声明”的时间依据。** [时间核查](reviews/chronology.md)发现冻结文件没有时间戳，只有计划哈希、自述及可修改的本地 mtime 支持先后顺序。若无更强的当时记录，可把稿件改为“使用确定性的循环置换”，不声称本轮独立证明了预声明。
2. **后期 parser 原始记录缺失。** 当前正文已明确是报告记载。选择继续保留这一限定、恢复正确的记录，或删去这段辅助执行主张；不能用另一个时期的 E5 结果补位。

无需手工重算数千个哈希。可以查看代码并在新的外部目录重跑所需检查，
但不能只看 agent 的 PASS 就完成签核。哪些原始文件无法访问，就把对应
子项记为无法核验。这里列的是核验顺序，不是只抽查一个文件就能通过全部主张。
