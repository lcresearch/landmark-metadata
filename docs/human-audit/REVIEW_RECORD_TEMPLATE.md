# Human review record — uncompleted template

This file contains no human verdict or attestation. Copy it to a new record;
do not overwrite earlier reviews. The actual reviewer supplies the observations
and signs only their own scope. Raw evidence and generated logs stay outside Git.

## Per-item observation — repeat this section

- Item, ledger claim IDs and exact manuscript clause: **[human to supply]**
- Earlier reported comparison target: **[human to supply; not the observation]**
- Inspection method: **[source/document reading / saved-record readback / independent saved-byte recomputation / fresh build and execution; specify what occurred]**
- Evidence-register rows inspected and rows still missing: **[human to supply]**
- Commands, environment and external output-record identities, if used: **[human to supply]**
- Coverage: **[conditions × consumers, actual inputs/positions inspected, omissions; do not count aliases or repeats as new models]**
- Actual observations, including false booleans, failures and stages not reached: **[human to supply]**
- Human conclusion and supporting reasoning tied to those observations: **[human to supply]**
- Per-subclaim status if coverage or outcomes differ: **[human to supply]**
- Remaining objections, uncertainty and manuscript wording that needs correction: **[human to supply]**

A source-only inspection may support a source-level statement. It does not by
itself authenticate excluded runtime bytes, graph preservation or reference
authority. Missing required evidence prevents SUPPORTED_WITHIN_SCOPE for that
claim, even when report prose and automated checks agree.
